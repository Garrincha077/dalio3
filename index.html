Dalio's All Weather Framework

This dashboard implements Ray Dalio's "All Weather" framework, which divides the macroeconomic environment into 4 quadrants along two fundamental axes: Growth (rising vs. falling) and Inflation (rising vs. falling). Each quadrant represents a unique regime where different asset classes outperform.

Growth Falling ↓Growth Rising ↑
Inflation Rising ↑ STAGFLATION

Inflation Falling ↓ DEFLATION / RECESSION

Data Source: Most indicator values can be transcribed from the Discipline Funds Macro Dashboard (Brian Massaro / Cullen Roche framework), which pulls data from FRED and related sources. Alternatively, enter a FRED API key for automated fetching.

Suggested All Weather Allocation Tilt

Dalio's base All Weather allocation is: 30% Equities, 40% Long-Term Treasuries, 15% Intermediate Bonds, 7.5% Gold, 7.5% Commodities. The idea is to tilt away from this base depending on the active quadrant:

Growth Score — Calculation

Each growth indicator produces a score from -1 (deep contraction) to +1 (strong expansion), using linear interpolation between historical thresholds:

score = (value − bearishThreshold) / (bullishThreshold − bearishThreshold) × 2 − 1

If value ≥ bullishThreshold → score = +1
If value ≤ bearishThreshold → score = −1

Weighted Growth Score = Σ(score_i × weight_i) / Σ(weight_i)

Inflation Score — Calculation

Each inflation indicator produces a score from -1 (strong disinflation) to +1 (hot inflation):

score = (value − fallingThreshold) / (risingThreshold − fallingThreshold) × 2 − 1

If value ≥ risingThreshold → score = +1 (inflation rising)
If value ≤ fallingThreshold → score = −1 (inflation falling)

Fed Net Liquidity

Based on Max Anderson's methodology. Fed Net Liquidity = Federal Reserve Balance Sheet (WALCL) − Treasury General Account (WTREGEN) − Overnight Reverse Repo (RRPONTSYD). All three FRED series are updated weekly. For this dashboard, enter the YoY % change in net liquidity. Current level is approximately $5.7T. Track it on StreetStats or via TradingView formula: WALCL-WTREGEN-RRPONTSYD.

Mini Heatbar

Each indicator has a mini gradient bar. Growth indicators: red (bearish) → yellow → green (bullish). Inflation indicators: blue (cool/disinflation) → yellow → red (hot/inflation). The white thumb shows where the current value sits within the scoring range.
